# Method

## Principles
1. Criteria are fixed **before** detailed reading (see `criteria.csv`).
2. Fact and interpretation are kept apart in every finding.
3. Paraphrase only; point to the section or figure.
4. Record the version and date accessed.
5. No composite score. Counts per criterion only.
6. "Not reported" = not visible to the reviewer in the document.

## Rating scale
Reported / Partly / Not reported / N/A (criterion does not apply to this evaluation).
One judgment criterion (J1, "conclusion follows from data") is rated Yes / Partly / No / Can't tell, with a written reason.

## Process
1. Read the introduction; list headline claims in your own words (`claims.csv`).
2. List each evaluation in scope with n, runs, uncertainty, grader, baseline (`evaluations.csv`).
3. Rate criteria C1-C11 per evaluation (`scoring.csv`).
4. Write findings: observation, pointer, fact/interpretation, consequence (Low/Medium/High, indicative), question to the authors (`findings.csv`).
5. Summarise counts per criterion (`summary.csv`).
6. Second pass: re-rate a sample after a delay; ideally a second reviewer.

## Note on the "validation area" column
It is an analogy to model-risk-management practice, not a regulatory requirement.

## Using the template
Copy `template/` to `cases/<new-case>/data/`, fill the sheets in the order above, and write the report.
